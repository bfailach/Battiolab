Aplicación de escritorio · Colombia

Ventas, inventario y cartera en un solo sistema.

battiolab opera una tienda y taller de vehículos eléctricos: factura conforme a la normativa DIAN, controla el inventario por lotes, sigue la cartera por antigüedad y administra clientes y nómina.

Módulos

Seis módulos cubren el ciclo completo de la operación.

Inicio

Ingresos del mes, ventas del día, cartera pendiente, carga del inventario y productos más vendidos.

Ventas

Facturas, venta de contado o a crédito, consumidor final, cartera por antigüedad, reportes y configuración.

Inventario

Existencias, alertas de stock, catálogo con imágenes, lotes, historial de movimientos y escaneo de códigos.

Clientes

Directorio, segmentos de mejores, recurrentes, nuevos y sin actividad, historial de compras y reportes.

Empleados

Directorio, departamentos, reportes de nómina y antigüedad, retiros, cargos y áreas.

Empresa

Datos del emisor, resolución de facturación DIAN, pie de factura, UVT y salario mínimo.

Reglas de negocio

La API aplica cada regla en el servidor. La interfaz no puede saltarlas.

Facturación

  • Requisitos del art. 617 del Estatuto Tributario y del art. 11 de la Resolución DIAN 000165 de 2023 que dependen del sistema.
  • Numeración con el prefijo y rango de la resolución. Se rechaza facturar fuera del rango o con la resolución vencida.
  • Facturas inmutables: se anulan con nota crédito y el inventario se repone.
  • Precio con IVA incluido desagregado en base e impuesto con total exacto.

Inventario

  • Cada venta descuenta stock. La venta sin existencias está bloqueada salvo configuración explícita.
  • Los lotes suman stock con costo, proveedor y garantía.
  • Todo cambio de existencias queda en el historial de movimientos.
  • Un producto con ventas o lotes se descontinúa, no se elimina.

Clientes y usuarios

  • Cédula de 6 a 10 dígitos y NIT de 9 dígitos con dígito de verificación calculado.
  • Teléfonos de 10 dígitos: celular 3xx o fijo 601 a 608.
  • Las ventas a crédito exigen un cliente identificado.
  • Solo los administradores modifican la configuración.

battiolab no transmite documentos a la DIAN. El CUFE, la firma digital y el código QR los asigna un proveedor tecnológico autorizado.

Arquitectura

Cliente de escritorio aislado sobre una API REST con MongoDB.

EscritorioElectron

Proceso principal con contextIsolation y sin nodeIntegration.

InterfazReact + Material UI

TypeScript, React Router y Recharts.

HTTP + JWT
APIExpress

Validación, reglas de negocio, numeración y permisos.

DatosMongoDB

Modelos con Mongoose e imágenes de productos en disco.

  • Los totales, el IVA, la numeración y el stock se calculan en el servidor.
  • La autenticación usa JWT y las contraseñas se almacenan con hash bcrypt.
  • Cada push y pull request ejecuta auditoría de dependencias, lint, pruebas con cobertura y build en GitHub Actions.

Instalación

Requisitos: Node.js 18 o superior y MongoDB 6 o superior, local o remoto.

Instalar y ejecutar

git clone https://github.com/bfailach/Battiolab.git
cd Battiolab
npm install
npm install --prefix server
cp server/.env.example server/.env

# con MongoDB en ejecución
npm run app   # compila e inicia la aplicación
npm run dev   # modo desarrollo

Variables de server/.env

VariableUso
MONGODB_URICadena de conexión a MongoDB. Obligatoria.
JWT_SECRETClave larga y aleatoria para firmar sesiones. Obligatoria.
PORTPuerto de la API. Por defecto 3006.
SITE_CODECódigo de sede exigido en el registro.
CORS_ORIGINSOrígenes permitidos, separados por comas.
UPLOAD_DIRCarpeta de imágenes de productos.
